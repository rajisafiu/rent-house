# Smart Property

Smart Property is a mobile-first property discovery and rental management app for the Ikorodu, Lagos market. It is built as a JavaScript/React Native Expo app and follows the blueprint provided for local discovery, transparency, verification, and property management.

## Features in this prototype

- Property discovery with featured listings
- Search and filtering by category and budget
- Saved homes and saved searches
- Property detail screen with cost and feature breakdown
- Tenant account overview and quick actions

## Run it locally

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Stack

- Expo + React Native
- Expo Router
- JavaScript / JSX (no TypeScript)

## Notes

This project was converted from the default starter template into a JavaScript Smart Property prototype based on the supplied project blueprint.
